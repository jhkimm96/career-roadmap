X-Window 원격 활용 ⭐⭐
기출 포인트: xhost vs xauth, DISPLAY 환경변수
명령/파일설명
xhostX서버에 접속할 수 있는 클라이언트를 IP 기반으로 허가/해제
xauthMMC 방식 인증 (쿠키 기반, 더 안전)
.XauthorityX윈도 실행 시 관련 키 정보 저장 파일
DISPLAYX 클라이언트를 원격지로 전송하기 위해 변경하는 환경변수
xhost 명령의미
xhost + IP주소해당 IP 접근 허가
xhost - IP주소해당 IP 차단
xhost + (디폴트)명시적 차단 클라이언트 외 모두 허용
xhost -명시적 허용 클라이언트 외 모두 차단
# DISPLAY 환경변수 설정 형식 export DISPLAY="IP주소:디스플레이번호.스크린번호" export DISPLAY="192.168.1.10:0.0" # 번호는 0부터 시작 # xauth 쿠키 확인 xauth list $DISPLAY
