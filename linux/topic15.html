네트워크 관련 명령어 ⭐⭐
명령어역할
ifconfig네트워크 인터페이스 구성/확인
ping통신 가능 여부 점검 (ICMP 기반)
traceroute패킷 전달 경로 확인
route라우팅 테이블 확인
netstat네트워크 연결 상태 확인. -r(라우팅), -t(TCP), -n(숫자)
nslookup도메인 네임서버에 호스트 정보 질의 (대화식)
arpARP 테이블 확인/추가/삭제. -a(캐시정보 확인)
mii-tool네트워크 카드에 케이블 물리적 연결 여부 점검
ethtool이더넷 카드 설정 정보 출력/변경, 물리적 연결 확인
ss소켓 정보 출력 (netstat 대체). -a(전체), -t(TCP)
💡 구분 암기

라우팅 테이블 확인: route, netstat -r, ip route show

MAC 주소 확인: arp, ifconfig, ip

케이블 연결 확인: mii-tool, ethtool

네트워크 설정 파일
파일내용
/etc/hostsIP주소와 호스트명 매핑. DNS 쿼리 전 먼저 탐색
/etc/resolv.confDNS 서버 주소 설정 (nameserver 지정)
/etc/services인터넷 서비스 관련 포트번호 확인
/etc/protocols서비스 가능한 프로토콜 목록
/etc/sysconfig/network-scripts/네트워크 인터페이스 환경설정 파일 디렉터리
