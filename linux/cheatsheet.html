🔥 매회 출제
🔐 권한 & 특수권한
권한숫자의미
r4읽기
w2쓰기
x1실행
rwx7모든 권한
rw-6읽기+쓰기
r-x5읽기+실행
r--4읽기만
chmod 755 file # rwxr-xr-x chmod 644 file # rw-r--r-- chmod u+x file # 소유자에 실행 추가 chown user:group file
특수권한숫자대상효과
SetUID4파일실행 시 소유자 권한으로 실행
SetGID2파일/디렉터리실행 시 그룹 권한으로 실행
Sticky Bit1디렉터리본인 파일만 삭제 가능 (예: /tmp)
chmod 4755 file # SetUID (s표시) chmod 2755 dir # SetGID chmod 1777 dir # Sticky Bit (t표시) ls -l → -rwsr-xr-x # SetUID 확인
💡 umask 계산

파일 기본권한 666 − umask = 실제 권한

디렉터리 기본권한 777 − umask = 실제 권한

umask 022 → 파일 644, 디렉터리 755

umask 077 → 파일 600, 디렉터리 700 (가장 안전)
