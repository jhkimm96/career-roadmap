서브넷 계산 ⭐⭐
기출 포인트: 서브넷 개수, 호스트 수, 게이트웨이 주소 계산
📐 계산 공식

서브넷 개수 = 2^(빌린 비트 수)

서브넷당 호스트 수 = 2^(호스트 비트 수) - 2 (네트워크/브로드캐스트 주소 제외)

📌 예제: C클래스 255.255.255.192 (/26)

마지막 옥텟: 11000000 → 서브넷 비트 2개 빌림

서브넷 개수: 2^2 = 4개

호스트 수: 2^6 - 2 = 62개

⭐ 기출 예제: IP 192.168.5.150, 서브넷마스크 255.255.255.192

192 = 11000000 → 호스트 비트 6개

192.168.5.128/26 네트워크 → 게이트웨이 보통 192.168.5.129
