프린터 명령어 ⭐⭐
기출 포인트: BSD계열 vs System V계열 명령어 구분
계열명령설명
BSD 계열lpr프린터 작업 요청. -#(매수), -r(파일삭제)
lpq프린터 큐 작업 목록 출력
lprm프린터 큐 대기 작업 삭제
lpc라인 프린터 컨트롤 프로그램
System V 계열lp프린터 작업 요청. -n(매수)
lpstat프린터 큐 작업 상태 확인
cancel프린트 작업 취소
💡 구분 암기

BSD: lpr/lpq/lprm/lpc (r이 들어감)

System V: lp/lpstat/cancel (r 없음)

lp는 System V 계열이라 BSD와 계열이 다름
