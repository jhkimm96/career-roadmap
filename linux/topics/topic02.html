💡 리눅스 파일 3종류 (틀린 것 구분)

일반 파일 / 디렉터리 / 특수 파일(장치·소켓·파이프) → 백업 파일은 별도 종류가 아님

파일명에 공백·필드분리자 포함 가능 ("포함할 수 없다"는 틀린 설명)

마운트 관련 명령어
명령어설명주요 옵션
mount장치와 디렉터리 연결-t (파일시스템 타입), -o (옵션)
umount연결 해제 (unmount 아님!)-a: /etc/mtab 전체 해제
eject이동식 보조기억장치 제거-
# ext4 파일시스템으로 마운트 mount -t ext4 /dev/sdb1 /data # 읽기/쓰기로 재마운트 mount -o remount,rw /home # 윈도우 공유폴더 마운트 (cifs) mount -t cifs //192.168.5.13/data /mnt # FAT-32(윈도우) 읽기 전용 마운트 mount -t vfat -o ro /dev/sda1 /mnt # ISO 이미지 읽기 전용 마운트 (loop 옵션) mount -t iso9660 -o ro,loop /test.iso /mnt # IDE P-ATA 2번째 디스크 1번째 파티션 → /dev/hdb1 # hda=1번째, hdb=2번째 | 1=첫파티션 mount -t ext4 -o ro /dev/hdb1 /mnt
파티션 & 파일시스템 생성
명령어역할옵션
fdisk파티션 생성/삭제/타입결정-l(목록), -s(크기출력), d(삭제), n(새파티션), t(타입변경), w(저장), q(종료)
mkfs파일시스템 생성(포맷)mkfs.xfs, mkfs.ext4
mke2fsext2/3/4 포맷-j(ext3 저널링), -t(타입지정)
⭐ 기출 핵심
  • mke2fs -j /dev/sdb1 → 자동으로 ext3으로 생성 (저널링)
  • mke2fs -t ext4 /dev/sdX → ext4 타입 지정
  • mkfs.xfs /dev/sdb1 → xfs 파일시스템 생성
  • fdisk 작업 순서: 파티션 작업 → mkfs/mke2fs로 파일시스템 생성
  • 새 HDD 추가 전체 순서: fdisk → mkfs → mount
  • fdisk t 명령 = 파티션 타입 변경 (마운트 아님 — 틀린 설명 주의)
  • fdisk -s 파티션 = 파티션 크기 출력

/etc/fstab ⭐⭐⭐
기출 포인트: 필드 번호와 의미, 특히 4번째(옵션) 필드
# <파일시스템> <마운트포인트> <타입> <옵션> <dump> <pass> # 1 2 3 4 5 6 UUID=1234-5678 / ext4 defaults 1 1 /dev/sdb1 /mnt/backup ext4 defaults 0 2 /dev/sr0 /mnt/cdrom iso9660 noauto,user 0 0
필드내용
1번째장치명, UUID, LABEL, 네트워크 주소
2번째마운트 포인트
3번째파일시스템 타입
4번째 ★마운트 옵션 (defaults, ro, rw, noauto 등)
5번째dump (백업 여부, 0=안함, 1=함)
6번째 ★fsck 검사 순서 (0=안함, 1=루트, 2=나머지)
관련 파일설명
/etc/fstab파일시스템 정적 정보. 부팅 시 마운트할 파티션 정보
/etc/mtab현재 마운트된 파일시스템 정보
/etc/mounts파일시스템이 실제 마운트 여부와 관계없이 보여줌

LVM (Logical Volume Manager) ⭐
🔑 LVM 구성 순서 (반드시 암기!)

PV → VG → LV

Physical Volume → Volume Group → Logical Volume

용어풀네임설명
PVPhysical Volume물리적 디스크/파티션
PEPhysical ExtentPV의 블록 단위
VGVolume GroupPV들의 묶음
LVLogical VolumeVG에서 생성하는 논리적 파티션
RAID
레벨기술특징최소 디스크
RAID-0스트라이핑속도 ↑, 백업 없음 (하나 고장 시 전체 손실)2개
RAID-1미러링디스크 이중화, 50% 효율2개
RAID-5패리티 1개1개 고장 복구 가능3개
RAID-6패리티 2개2개 고장 복구 가능4개
💡 용량 계산

RAID-0: 전체 용량 사용 | RAID-1: 절반 | RAID-5: (n-1)개 용량 | RAID-6: (n-2)개 용량

예) 10GB 디스크 8개, 스페어 1개, RAID-5 → (8-1-1) × 10 = 60GB
