History 기능
기출 포인트: !!, !n, !?문자열 의미, HISTSIZE 변수
명령의미
!!마지막으로 실행했던 명령 재실행
!nn번째 명령어 실행
!-n현재에서 n번째 이전 명령어 실행
!문자열가장 최근에 '문자열'로 시작하는 명령 실행
!?문자열가장 최근에 '문자열'을 포함하는 명령 실행
!$, !!$마지막 명령의 마지막 인자
!*마지막 명령에 사용된 모든 인자
환경변수의미
HISTSIZE히스토리 스택의 크기 (메모리에 저장)
HISTFILE히스토리 파일 위치 (기본: ~/.bash_history)
HISTFILESIZE물리적인 히스토리 파일 크기
HISTTIMEFORMAT히스토리 명령어 수행 시간 출력 형태
HISTCONTROL중복 명령 기록 유무 지정
💡 HISTSIZE vs HISTFILESIZE

HISTSIZE = 메모리(스택) 크기 | HISTFILESIZE = 파일 크기

alias (에일리어스)
alias ll='ls -l' # alias 설정 alias # 현재 설정된 alias 목록 unalias ll # alias 해제 \ls # alias 무시하고 원래 ls 실행
⭐ 기출 핵심

ls에 alias 설정 시 원래 ls 실행 → \ls (백슬래시)

alias는 bash, csh 등 대부분의 셸에서 사용 가능 → "csh에서만 사용 가능"은 틀린 설명

셸 변수 관련 명령
명령역할
set선언된 셸 변수 및 함수 출력
env현재 셸의 환경 변수 출력 및 명령 실행
printenv현재 셸 환경의 환경 변수들 출력
unset환경 변수나 함수 제거
export환경변수로 선언 (자식 프로세스에 전달)
$ user=lin $ echo $user # lin 출력 $ set # 셸 변수+함수 전체 출력 $ env # 환경 변수만 출력 $ unset user # user 변수 제거
