단일 보드 컴퓨터 (SBC) ⭐ 2026.06 기출
기출 포인트: SBC가 아닌 것 고르기 (Arduino 함정)
구분보드
SBC (단일보드컴퓨터)Raspberry Pi, BeagleBone Black, Orange Pi, Jetson Nano
SBC 아님Arduino (마이크로컨트롤러 보드, MCU)
💡 암기

SBC = 기판 하나에 CPU·메모리·입출력을 모두 갖춘 완전한 컴퓨터 → 리눅스 등 OS 구동 가능

Arduino = MCU 기반 제어 보드, OS 없이 단순 반복 제어용 → SBC 아님

리눅스 기반 시스템 정리 ⭐ 2026.06 기출
기출 포인트: "리눅스 커널을 사용하는 OS는?" / "리눅스와 가장 거리가 먼 것은?"
구분OS
리눅스 기반Android, Ubuntu, Debian, Fedora, CentOS, RHEL, SUSE, Tizen
유닉스 계열 (리눅스 아님)macOS, FreeBSD, Solaris
리눅스 기반 아님Windows, DOS, OS/2
💡 암기

"리눅스 커널을 사용하는 OS는?" → 보기에 Android 있으면 정답

"리눅스와 가장 거리가 먼 것은?" → 보기에 Windows 있으면 정답

macOS/FreeBSD/Solaris는 유닉스 계열이지 리눅스는 아님 (헷갈리기 쉬움)
