계열셸경로개발자/특징
Bourne
계열		본셸(sh)/bin/sh스티븐 본, 벨 연구소, 기본 셸
콘셸(ksh)/bin/kshAT&T 데이비드 콘, 본셸 확장
배쉬셸(bash)/bin/bashGNU 프로젝트, Linux 표준, POSIX 호환
지셸(zsh)/bin/zshKorn shell 재작성
C셸
계열		C셸(csh)/bin/csh버클리대학 빌 조이, C언어 기반
tcsh/bin/tcsh확장 C셸, 1981년, BSD계열
기타dash/bin/dashDebian에서 sh 대체품
💡 기출 암기

GNU 프로젝트 셸 = bash (브라이언 폭스가 개발)

등장 순서: sh → csh → tcsh → ksh → bash → zsh

셸 확인 & 변경
방법명령어설명
현재 셸 확인echo $SHELL로그인 후 사용 중인 셸 확인
사용 가능 셸 목록cat /etc/shells시스템에서 사용 가능한 셸 목록
사용 가능 셸 목록chsh -l/etc/shells 내용 나열
특정 사용자 셸 확인grep 사용자 /etc/passwd/etc/passwd 파일에서 확인
셸 변경chsh -s /bin/bash로그인 셸 변경
관리자 셸 변경usermod -s /bin/bash ihd관리자가 특정 사용자 셸 변경
파일내용
/etc/shells사용 가능한 셸 목록. chsh로 변경 가능한 셸 나열
/etc/passwd각 사용자의 로그인 셸 정보 저장
$ echo $SHELL /bin/bash $ chsh -l # 사용 가능한 셸 목록 $ chsh -s /bin/zsh # 기본 셸을 zsh로 변경 $ usermod -s /bin/bash ihd # ihd 사용자 셸 bash로 변경
환경설정 파일
기출 포인트: 전역/지역 구분, 각 파일의 역할
구분파일역할
전역 설정
(/etc)		/etc/profile모든 사용자에게 적용되는 환경변수와 시작관련 프로그램 설정
/etc/bashrc모든 사용자에게 적용되는 alias와 함수 설정
지역 설정
(~/)		~/.bash_profile일반 사용자가 PATH 같은 환경변수 변경할 때 사용
~/.bashrc별칭(alias)과 함수를 지역적으로 제어
~/.bash_history사용자가 입력한 명령 기록 저장
~/.bash_logout로그아웃 시 실행
기타/etc/profile.d응용프로그램 시작 시 필요한 스크립트 위치
💡 구분 암기

/etc/profile = 전역 환경변수 | /etc/bashrc = 전역 alias/함수

~/.bash_profile = 지역 환경변수 | ~/.bashrc = 지역 alias/함수

주요 환경 변수
변수설명
SHELL현재 사용 중인 셸
PATH실행 파일 검색 경로
HOME홈 디렉터리
PS1셸 프롬프트 모양 결정 (1차 프롬프트)
PS22차 프롬프트 (명령어가 다음 줄로 연장될 때)
TERM터미널 종류
TMOUT로그아웃 관련 시간 제어
LANG프로그램 사용 시 기본 지원 언어. LANG=C → 영어 / echo $LANG으로 확인
PROMTC셸에서 사용, 프롬프트 형식 지정
프롬프트 형식 (PS1)
특수문자의미
\h호스트명
\u현재 사용자 이름
\t24시간 형식 현재 시간
\d요일 월 일 형태로 날짜
\w현재 작업 디렉터리 절대 경로
\W현재 작업 디렉터리의 마지막 디렉터리명
\s사용 중인 셸 이름
# 예시: [사용자@호스트 디렉터리]$ PS1='[\u@\h \W]\$ ' # 결과: [posein@www ~]$
