tar 옵션 ⭐⭐
옵션의미
c파일 묶기(create)
xtar 파일 풀기(extract)
t묶인 파일 목록 보기(table)
v처리 과정 출력(verbose)
f파일명 지정(file)
zgzip 압축/해제 (.gz)
jbzip2 압축/해제 (.bz2)
Jxz 압축/해제 (.xz)
Zcompress 압축/해제 (.Z)
r기존 tar 파일에 파일 추가(reappend)
P절대 경로로 정보 출력
C디렉터리 변경(change directory)
# gzip 압축 해제 tar zxvf file.tar.gz # bzip2 압축 해제 tar jxvf file.tar.bz2 # xz 압축 해제 tar Jxvf file.tar.xz # C언어 파일만 묶기 tar cvf source.tar *.c # 압축된 tar 내용 확인 (해제 안 함) tar jtvf php-8.2.7.tar.bz2
압축 명령어 & 압축률 순서
압축해제확장자
compressuncompress.Z
gzipgunzip.gz
bzip2bunzip2.bz2
xzunxz.xz
🔑 압축률 순서 (낮→높)

compress < gzip < bz2 < xz

xz가 가장 높은 압축률

명령주요 옵션설명
gzip-v압축/해제 시 진행 정보 + 압축률 출력 (verbose)
xz-d압축 해제 (decompress), unxz와 동일
xz-dv압축 해제 + 진행 상황 출력
소스 파일 설치 순서 ⭐⭐
🔑 반드시 암기!

./configure → make → make install

단계명령역할
1단계./configure환경 설정, Makefile 생성, PATH 지정 (설치 경로 지정)
2단계makeMakefile로 소스 코드 컴파일, 실행 파일 생성
3단계make install컴파일된 프로그램을 시스템에 설치
기타make clean이전 작업 설정/파일 삭제 후 재설정
📌 CMake 사용 프로젝트

CMake(Cross Platform Make): 멀티플랫폼, MAKE 대용품, 윈도우도 가능

CMake 사용: MySQL, KDE, LMMS

→ "CMake는 크로스 컴파일이 불가능하다"는 틀린 설명 — CMake는 크로스 컴파일 가능
