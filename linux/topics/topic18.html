국제기구 ⭐⭐
기관역할
IANAICANN 등장 이전 IP주소/도메인 관리. 한국은 KISA
ICANN현재 IP주소, 인터넷 도메인 관리 국제기구
ISO국제적인 표준화 기구 → OSI 7계층 제정
IEEE전기공학/전자공학 전문가 단체 → LAN 관련 표준 (802.x)
ITU-T국제 전기통신연합 → 통신 분야 표준 책정
CCITT국제 전신전화 자문위원회
TIA통신 분야 기업 협회, 통신 관련 표준 제정
EIA전자 산업 협회 → LAN 케이블 관련 표준 (RS-232C, T568B)
💡 암기

OSI 제정 → ISO | LAN 표준 → IEEE | LAN 케이블 → EIA

IP/도메인 관리 → IANA → ICANN (순서 중요)

인터넷 서비스
서비스설명
WWW하이퍼텍스트 기반 정보 검색 시스템, URL 사용
Gopher텍스트 기반 메뉴 인터페이스로 정보 검색
Usenet텍스트 기사를 공개된 공간에서 토론하는 분산 네트워크
IRCInternet Relay Chat. 실시간 인터넷 채팅 프로토콜
FTP파일 전송 프로토콜. 20(데이터)/21(제어)
NFSNetwork File System. 리눅스 시스템 간 파일 공유
SAMBA리눅스-윈도우 간 파일/하드웨어 공유. SMB→CIFS 프로토콜
SAMBA vs NFS 관련 용어 ⭐⭐
구분관련 용어
SAMBASMB, CIFS, NetBIOS, nmbd, smbd, smb.conf
NFSRPC, NFS, rpcbind(= portmap)
💡 암기

SAMBA = 리눅스↔윈도우 공유. SMB→CIFS 프로토콜, 데몬은 smbd(파일/프린터 공유), nmbd(NetBIOS 이름 서비스), 설정파일은 smb.conf

NFS = 리눅스↔리눅스 공유. RPC(Remote Procedure Call) 기반으로 동작 → rpcbind(=portmap) 데몬 실행이 선행되어야 함

파일/명령설명
