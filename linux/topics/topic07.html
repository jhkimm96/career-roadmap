vi 편집기 ⭐⭐⭐
기출 포인트: 모드 전환, 명령어, 치환 패턴, 환경설정 파일
📌 3가지 모드

명령 모드 (기본) ↔ 입력 모드 (i, a, o) ↔ 편집(ex) 모드 (:)

구분명령설명
입력모드
전환		i현재 커서 위치에서 입력
a커서 다음 위치에서 입력
o현재 줄 아래에 새 줄 입력
명령 모드dd현재 줄 한 라인 삭제
yy한 라인 복사
p커서 아래/오른쪽에 붙여넣기
P커서 위/왼쪽에 붙여넣기
uundo (직전 삭제한 줄 복원)
x현재 커서 위치 문자 삭제
커서이동h j k l←↓↑→ 방향 이동
j = 아래j(아래), k(위), h(왼쪽), l(오른쪽)
ex 모드
(:)		:wq저장하고 종료
:q!저장 않고 강제 종료
:w저장 (종료 안함)
:q종료 (수정 없을 때만)
:set nu / :set number줄 번호 표시
:set nonu줄 번호 해제 → :set notnu 는 없는 명령 (틀린 것)
3yy현재 행부터 3행 복사
vi 문자열 치환 ⭐⭐
# 기본 형식 :%s/찾을내용/바꿀내용/g # 전체에서 windows → linux 치환 :%s/windows/linux/g # 줄 시작이 linux인 것만 :%s/^linux/Linux/g # 단어 시작이 linux인 것만 (단어 경계) :%s/\<linux/Linux/g # linux로 끝나는 줄에 마침표 추가 :%s/linux$/linux./g # ^ = 줄 시작, $ = 줄 끝
기호의미
^줄의 시작
$줄의 끝
\<단어 시작 경계
\>단어 끝 경계
g해당 줄 전체 (없으면 첫 번째만)
vi 환경설정 파일
파일설명
.exrcvi 편집기 환경설정 등록 파일 (사용자 홈에 위치)
.vimrcvim 설정 파일
# vi 실행 시 자동으로 행번호 표시되게 하려면 ~/.exrc 파일에 set nu 추가 # 파일 열 때 특정 줄로 이동 vi +20 filename # 20번째 줄로 이동 vi -c 20 filename # vi +20과 동일 vi + filename # 마지막 줄로 이동 # 비정상 종료 후 복구 vi -r filename # 비정상 종료된 파일 복구 # 비정상 종료 시 생성되는 swap 파일: .파일명.swp (숨김파일) # 예) file.txt → .file.txt.swp
emacs 주요 단축키
단축키기능
Ctrl+X, Ctrl+C편집 종료
Ctrl+A커서를 줄의 맨 앞으로
Ctrl+E커서를 줄의 맨 뒤로
Ctrl+S 문자열커서 아래방향 문자열 검색
Ctrl+R 문자열커서 위방향 문자열 검색
Ctrl+F커서를 오른쪽으로 이동
nano 주요 단축키
단축키기능
Ctrl+X종료
Ctrl+O파일 저장 (write Out)
Ctrl+A현재 행의 시작으로
Ctrl+E현재 행의 끝으로
Ctrl+I탭 삽입
💡 nano = pico 기반

nano = GNU 프로젝트, 자유소프트웨어 O | pico = 워싱턴대학, 자유소프트웨어 X

→ "nano는 자유소프트웨어 아님"은 틀린 설명

⚠️ emacs 틀린 설명 주의

"시스템과의 호환성은 우수하지 않다" → 틀림. emacs는 호환성 우수
