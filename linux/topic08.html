RPM 옵션 ⭐⭐⭐
옵션의미예시
-i설치(install)rpm -i package.rpm
-U업그레이드(없으면 설치)rpm -U package.rpm
-e제거(erase)rpm -e nmap
-Ffreshen(설치된 것만 업그레이드)rpm -F package.rpm
-q질의(query)rpm -q nmap
-qi패키지 상세 정보rpm -qi nmap
-ql패키지 파일 목록rpm -ql nmap
-qa설치된 모든 패키지rpm -qa
-qf파일이 속한 패키지 역추적rpm -qf /bin/ls
--nodeps의존성 무시rpm -e nmap --nodeps
--force강제 설치 (replacekgs 포함)rpm -i pkg --force
-h설치 과정 해시(#)로 표시
-V파일 변조 여부 검사
⭐ RPM 파일명 형식

sendmail-8.14.3-5.fc11.i586.rpm

패키지명 - 버전 - 릴리즈번호 . 페도라버전 . 아키텍처 .rpm

YUM 명령어
명령설명
yum install 패키지명설치 (의존성 자동 해결)
yum remove 패키지명제거
yum update 패키지명업데이트
yum search 문자열패키지 검색
yum info 패키지명패키지 정보 (미설치도 가능)
yum list전체 패키지 목록
yum groupinstall 그룹명패키지 그룹 설치
yum check-update업데이트 가능 목록
dpkg & apt-get (데비안)
dpkg 옵션설명
-i패키지 설치
-r패키지만 삭제 (설정 파일 유지)
-P패키지 + 설정파일 모두 삭제
-s패키지 정보 출력
-L설치된 파일 목록
apt-get 명령설명
apt-get install 패키지설치
apt-get remove 패키지패키지만 제거
apt-get purge 패키지패키지 + 설정파일 모두 제거
💡 dpkg -r vs -P

-r(remove): 패키지만 삭제 | -P(purge): 설정파일까지 모두 삭제
