소유권 관련 명령어
기출 포인트: chown 형식, -R 옵션, 콜론(:) 구분자
명령어형식설명
chown chown [옵션] 소유자[:그룹] 파일명 소유자/그룹 소유권 변경. 그룹 앞에 콜론(:) 사용
chown -R root ihd -R : 하위 디렉터리 포함 재귀 변경
chown :root test 그룹 소유권만 root로 변경
chgrp chgrp [-h] 그룹명 파일명 그룹 소유권만 변경. -h: 심볼릭링크 그룹 변경
⚠️ 기출 자주 나오는 형식
  • chown ihduser:kait lin.txt → lin.txt 소유자=ihduser, 그룹=kait
  • chown kait:ihduser lin.txt → 소유자=kait, 그룹=ihduser
허가권 (chmod)
기출 포인트: 숫자 계산, 레퍼런스 클래스(u/g/o/a), 연산자(+/-/=)
모드이름숫자값
r읽기(read)4
w쓰기(write)2
x실행(execute)1
클래스의미
u소유자(owner)
g그룹(group)
o기타 사용자(others)
a모든 사용자(all) = ugo
# 기본 권한 파일: 666 (rw-rw-rw-) 디렉터리: 777 (rwxrwxrwx) # 예시 chmod 755 file # rwxr-xr-x chmod g=r lin.txt # 그룹 읽기만 chmod -R o+w TST # 하위 전체 기타사용자 쓰기추가 chmod a=rx file # 모든 사용자 읽기+실행 chmod u-x file # 소유자 실행 제거
umask
기출 포인트: umask 값으로 생성되는 파일/디렉터리 권한 계산
📐 계산법

파일 기본권한(666) - umask = 파일 허가권

디렉터리 기본권한(777) - umask = 디렉터리 허가권

umask 값파일 생성 권한디렉터리 생성 권한
0022644 (rw-r--r--)755 (rwxr-xr-x)
0002664 (rw-rw-r--)775 (rwxrwxr-x)
0000666 (rw-rw-rw-)777 (rwxrwxrwx)
💡 암기 팁

umask 0022 → 파일 644, 디렉터리 755 (가장 자주 출제!)

특수권한 ⭐⭐⭐
기출 포인트: SetUID/SetGID/Sticky Bit 숫자값, 적용 대상, chmod 예시
종류숫자기호설명적용대상
SetUID 4000 s (소유자 실행자리) 실행 시 소유자 권한으로 실행 실행파일
SetGID 2000 s (그룹 실행자리) 실행 시 그룹 권한으로 실행. 디렉터리에 설정 시 파일 생성 시 그룹 자동 부여 실행파일, 디렉터리
Sticky Bit 1000 t (기타 실행자리) 파일 삭제 시 소유자만 삭제 가능. /tmp에 설정됨 디렉터리
⭐ 기출 핵심 예시
  • /usr/bin/passwd → SetUID 설정 (일반사용자도 비밀번호 변경 가능)
  • Sticky Bit(1) + SetGID(2) = chmod 3770 /project
  • 그룹 사용자 파일 삭제 본인것만 → Sticky Bit
  • 파일 생성 시 그룹 자동 부여 → SetGID
chmod 4755 file # SetUID (rwsr-xr-x) chmod 2770 /dir # SetGID chmod 1777 /tmp # Sticky Bit (/tmp 기본값) chmod 3770 /proj # Sticky + SetGID chmod o+t /project # Sticky Bit 추가
