⭐ 반드시 암기
  • DNS = TCP/UDP 둘 다 (유일하게 둘 다 사용)
  • SNMP = UDP (161)
  • DHCP = UDP (67/68)
  • FTP = 20(데이터) + 21(제어) 두 개
  • SSH(22) vs Telnet(23) — SSH가 번호 더 작음, 더 안전
